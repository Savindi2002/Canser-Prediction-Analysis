# 🧬 Cancer Prediction Analysis

A machine learning and data analysis project focused on analyzing cancer-related patient data and predicting cancer diagnosis using Python and machine learning techniques.

## 📌 Project Overview

This project explores a cancer dataset containing patient-related medical features. The workflow includes data exploration, visualization, preprocessing, and machine learning model development to identify patterns associated with cancer diagnosis.

The main goal is to understand the dataset and build a predictive model that can classify whether a patient is likely to have cancer based on the available features.

## 🎯 Objectives

* Explore and understand the cancer dataset
* Perform exploratory data analysis (EDA)
* Analyze the distribution of important features
* Identify relationships and patterns within the data
* Prepare the data for machine learning
* Train a classification model
* Evaluate the model's predictive performance
* Visualize important findings

## 🔍 Analysis Workflow

The project follows these main steps:

1. **Data Loading**
2. **Data Cleaning**
3. **Exploratory Data Analysis**
4. **Feature Analysis**
5. **Data Preprocessing**
6. **Model Training**
7. **Model Evaluation**
8. **Data Visualization**

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Scikit-learn**
* **Jupyter Notebook**


## 📈 Visualizations

The project includes visual analysis of numerical features to better understand the distribution and characteristics of the dataset.

## 🤖 Machine Learning

The project applies machine learning techniques to the processed dataset for cancer classification.

Model performance can be evaluated using metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Savindi2002/Canser-Prediction-Analysis.git
```

### 2. Navigate to the project

```bash
cd Canser-Prediction-Analysis
```

### 3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 4. Open the notebook

```bash
jupyter notebook
```

Then open:

```text
notebooks/cancer_prediction.ipynb
```
